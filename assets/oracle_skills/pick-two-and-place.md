---
name: pick-two-and-place
description: Moving two identical objects to one receptacle
---

## When to use
The task asks for *two* of something in one place.

## Procedure
1. Carry them one at a time. You can only hold one object.
2. Find the first, `take` it, `go to <target>`, `put` it.
3. Then search for the second. It is usually in a *different* receptacle from the first.
4. `take` it, `go to <target>`, `put` it.

## Common failures
- Trying to take the second object while still holding the first.
- Returning to the receptacle that held the first one and finding it empty. Search elsewhere.
- Stopping after one. The task is not complete until both are placed.
